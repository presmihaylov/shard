Frequently asked questions
More in the docs ↗
How is Shard different from hosted sandboxes?
Shard runs on your own hardware. You control the infrastructure, data, access, and isolation provider. Use one API across multiple providers without relying on a hosted sandbox service.
How is this different from Docker?
Docker containers share the host kernel. Shard also offers user-space kernels and VM isolation, plus snapshots, pause/resume, forks, egress control, and credential brokering through one API. Features vary by runtime.
Where do the sandboxes run?
On your own Mac or Linux server. Shard is software you install and operate, rather than a hosted sandbox service.
Does every provider support the same features?
No. Pause, resume, fork, and other capabilities depend on the provider. Check the server capabilities before your agent uses them.
