## sandbox.exec

Execute a command in a running sandbox and return how it ended.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
sandbox.exec(command: string | string[], options?: ExecOptions): Promise<ExecResult>
sandbox.exec(command: string | string[], options: ExecOptions & { background: true }): Promise<Command>
```

</TabItem>
<TabItem label="Python">

```python
sandbox.exec(command, *, background=False, stdin=None, env=None, workdir=None, user=None,
             tty=False, output_limit_bytes=8388608, on_stdout=None, on_stderr=None)
    -> CommandResult | Command
```

</TabItem>
</Tabs>

**Examples**

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const result = await sandbox.exec(["echo", "hello"]);
const shell = await sandbox.exec("echo $GREETING from $(pwd)", { env: { GREETING: "hello" }, workdir: "/tmp" });
const sum = await sandbox.exec("wc -l", { stdin: "one\ntwo\n" });
const command = await sandbox.exec("sleep 5; echo done", { background: true });
```

</TabItem>
<TabItem label="Python">

```python
result = sandbox.exec(["echo", "hello"])
shell = sandbox.exec("echo $GREETING from $(pwd)", env={"GREETING": "hello"}, workdir="/tmp")
count = sandbox.exec("wc -l", stdin="one\ntwo\n")
command = sandbox.exec("sleep 5; echo done", background=True)
```

</TabItem>
</Tabs>

**Arguments**

| Argument | Description |
| --- | --- |
| `command` | a string runs under `/bin/sh -c`; an array or list runs as it is, with no shell |

**Options**

| TypeScript | Python | Description |
| --- | --- | --- |
| `env` | `env` | variables added to the sandbox's environment for this command |
| `workdir` | `workdir` | working directory |
| `user` | `user` | user name or uid in the sandbox |
| `stdin` | `stdin` | text or bytes the command reads, after which its input ends; `true` keeps the input open for `writeStdin` |
| `tty` | `tty` | run on a terminal: `{ rows, cols }` in TypeScript, `True` or `TerminalSize(rows, cols)` in Python; all output arrives as stdout |
| `signal` | | an `AbortSignal` that ends this client's wait |
| `onStdout`, `onStderr` | `on_stdout`, `on_stderr` | called with each chunk of output, as bytes, as it arrives |
| `outputLimitBytes` | `output_limit_bytes` | how many of the newest bytes of stdout and stderr together the result keeps; 8 MiB by default, 0 keeps none |
| `background` | `background` | return a [`Command`](#commandwait) as soon as the command is running |

**Result**

The result holds `exitCode`, `signal`, `stdout`, `stderr` and `lostBytes` (`exit_code`, `signal`, `stdout`, `stderr` and `lost_bytes` in Python). Python also has `stdout_bytes` and `stderr_bytes` with the raw bytes.

A non-zero exit code comes back in the result and raises nothing. When a signal ends a command, every provider reports the exit code as 128 plus the signal's number, such as 137 for `KILL`. A command that never started, for example because its binary does not exist, raises `CommandNotStartedError`.

**Output**

A result keeps the newest 8 MiB of stdout and stderr together, so the result of a long run may hold only the end of its output. The callbacks still see every chunk, including the ones past the limit. `lostBytes` counts something else: the output the daemon dropped before any client read it.

**Ending the wait**

An abort, an asyncio cancel, a Python `timeout` or a dropped connection ends only this client's wait and releases the stream. The command keeps running until it exits or until [`command.kill`](#commandkill).

**Input**

In Python, a foreground command takes its whole input as text or bytes, and a background command takes a bool: `True` keeps the input open for `write_stdin`. Any other mix raises `TypeError`.

In TypeScript, `sandbox.commands.run()` and `sandbox.commands.start()` do the same as `exec()` without and with `background: true`.

## command.wait

Wait for a background command to end and return how it ended.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
command.wait(options?: { signal?: AbortSignal }): Promise<ExecResult>
```

</TabItem>
<TabItem label="Python">

```python
command.wait(timeout=None) -> CommandResult
```

</TabItem>
</Tabs>

**Examples**

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const result = await command.wait();
const bounded = await command.wait({ signal: AbortSignal.timeout(30_000) });
```

</TabItem>
<TabItem label="Python">

```python
result = command.wait()
bounded = command.wait(timeout=30)
```

</TabItem>
</Tabs>

**Options**

| TypeScript | Python | Description |
| --- | --- | --- |
| `signal` | | an `AbortSignal` that ends the wait with the signal's reason |
| | `timeout` | seconds to wait before raising the built-in `TimeoutError` |

Ending the wait never ends the command.

## command.inspect

Read the command's record from the daemon.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
command.inspect(): Promise<CommandInfo>
```

</TabItem>
<TabItem label="Python">

```python
command.inspect() -> CommandInfo
```

</TabItem>
</Tabs>

**Examples**

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const { state, exitCode } = await command.inspect();
```

</TabItem>
<TabItem label="Python">

```python
info = command.inspect()
print(info.state, info.exit_code)
```

</TabItem>
</Tabs>

A `CommandInfo` holds `id`, the sandbox ID, `command`, `state` (`running` or `exited`), the exit code, `signal`, the start and exit times, and the lost bytes. The exit code is null while the command runs.

## sandbox.commands.get

Find a command by ID, from any client, and return a handle to it.

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
sandbox.commands.get(id: string, options?: OutputOptions): Promise<Command>
```

</TabItem>
<TabItem label="Python">

```python
sandbox.commands.get(id, *, output_limit_bytes=8388608, on_stdout=None, on_stderr=None) -> Command
```

</TabItem>
</Tabs>

**Examples**

<Tabs syncKey="lang">
<TabItem label="TypeScript">

```ts
const command = await sandbox.commands.get(id, { onStdout: (chunk) => process.stdout.write(chunk) });
const result = await command.wait();
```

</TabItem>
<TabItem label="Python">

```python
command = sandbox.commands.get(id, on_stdout=sys.stdout.buffer.write)
result = command.wait()
```

</TabItem>
</Tabs>

**Options**

| TypeScript | Python | Description |
| --- | --- | --- |
| `onStdout`, `onStderr` | `on_stdout`, `on_stderr` | called with each chunk of output as it arrives |
| `outputLimitBytes` | `output_limit_bytes` | how many of the newest bytes the result keeps |

The handle attaches on `wait`, so the callbacks see the output the daemon replays.
