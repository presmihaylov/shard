This stores a network policy named `web` with one rule. A sandbox with this policy can reach `api.example.com`, and the policy drops whatever its rules do not allow:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X PUT -H 'Content-Type: application/json' -d '{"rules":[{"action":"allow","rule":"api.example.com"}]}' http://localhost/v0/policies/web
```

A create names the policy, and so does an [attach](/docs/reference/api/sandboxes/#attach-a-policy-to-a-sandbox) to a stopped sandbox.

## List policies

`GET /v0/policies` · scope `policy:*`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | integer (int64) | no | The most rows a page holds; none answers the whole list. At least 1. |
| `cursor` | query | string | no | The next of the page before; this page starts after it. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [PoliciesResponse](#policiesresponse) as `application/json` |
