This forwards port 8080 on the host's 127.0.0.1 to port 3000 on the 127.0.0.1 of the sandbox `web`:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X PUT -H 'Content-Type: application/json' -d '{"guest_port":3000}' http://localhost/v0/sandboxes/web/ports/8080
```

With `"public":true` the forward listens on `0.0.0.0` instead, so anything that can reach the host can reach the port. A forward stays on the sandbox through a stop and a start; a fork does not copy it. A create can carry forwards in its `ports` field.

## Forward a host port into a sandbox, or change that forward

`PUT /v0/sandboxes/{id}/ports/{host_port}` · scope `port:write`

A PUT of the forward the host port already has changes nothing. A running sandbox listens at once; any other keeps the forward for its next start. The answer is 409 in\_use when another sandbox forwards the host port or another process on the host listens on it.

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `host_port` | path | integer (int32) | yes | The port on the host the forward listens on. From 1 to 65535. |

**Request body**

[PortRequest](#portrequest) as `application/json`, required.

**Responses**

| Status | Body |
| --- | --- |
| 200 | [Port](#port) as `application/json` |
