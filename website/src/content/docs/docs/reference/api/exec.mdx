This runs a command in the running sandbox `web`:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X POST -H 'Content-Type: application/json' -d '{"command":["/bin/echo","hi"]}' http://localhost/v0/sandboxes/web/exec
```

The daemon answers `201` with the [Exec](#exec). Routes with `{exec}` in the path use its `exec` field as the id. This one waits for the command to end:

```sh
curl --unix-socket /var/lib/shard/shard.sock 'http://localhost/v0/sandboxes/web/exec/<exec>?wait=true'
```

Each route answers an error with the [Error](/docs/reference/api/#error) body, unless its responses say otherwise.

## Execute a command in a running sandbox

`POST /v0/sandboxes/{id}/exec` · scope `exec`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |

**Request body**

[ExecRequest](#execrequest) as `application/json`, required.

**Responses**

| Status | Body |
| --- | --- |
| 201 | [Exec](#exec) as `application/json` |

## Read, wait for or attach to an exec

`GET /v0/sandboxes/{id}/exec/{exec}` · scope `exec`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `exec` | path | string | yes | The exec id. |
| `wait` | query | boolean | no | Block until the exec ends. |

**Responses**

| Status | Body | Description |
| --- | --- | --- |
| 101 | WebSocket | A WebSocket attach. Each binary message leads with its stream byte: 0 stdin and 4 stdin closed from the client; 1 stdout, 2 stderr, 3 the ExitMessage and 5 a FailureMessage from the daemon. |
| 200 | [Exec](#exec) as `application/json` | The exec as it stands, or with wait once it ends. |

**WebSocket messages**

| Stream byte | Payload |
| --- | --- |
| 3 | [ExitMessage](#exitmessage) |
| 5 | [FailureMessage](/docs/reference/api/sandboxes/#failuremessage) |
