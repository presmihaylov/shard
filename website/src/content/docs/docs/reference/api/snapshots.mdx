This saves the files of the stopped sandbox `web` as a snapshot, then creates a new sandbox from it:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X POST -H 'Content-Type: application/json' -d '{"sandbox":"web","name":"web-base"}' http://localhost/v0/snapshots
curl --unix-socket /var/lib/shard/shard.sock -X POST -H 'Content-Type: application/json' -d '{"snapshot":"web-base","name":"web-3","resources":{"memory_mib":512}}' http://localhost/v0/sandboxes
```

To create a sandbox from a snapshot, use the create route in [Sandboxes](/docs/reference/api/sandboxes/#create-a-sandbox).

## Snapshot a sandbox

`POST /v0/snapshots` · scope `sandbox:write`

**Request body**

[SnapshotRequest](#snapshotrequest) as `application/json`, required.

**Responses**

| Status | Body |
| --- | --- |
| 201 | [Snapshot](#snapshot) as `application/json` |

## List snapshots

`GET /v0/snapshots` · scope `sandbox:read`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | integer (int64) | no | The most items on a page; absent returns the whole list. At least 1. |
| `cursor` | query | string | no | The next value of the previous page; this page starts after it. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [SnapshotsResponse](#snapshotsresponse) as `application/json` |

## Read a snapshot

`GET /v0/snapshots/{ref}` · scope `sandbox:read`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ref` | path | string | yes | The snapshot id or name. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [Snapshot](#snapshot) as `application/json` |

## Remove a snapshot

`DELETE /v0/snapshots/{ref}` · scope `sandbox:delete`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ref` | path | string | yes | The snapshot id or name. |

**Responses**

| Status | Body |
| --- | --- |
| 204 | none |
