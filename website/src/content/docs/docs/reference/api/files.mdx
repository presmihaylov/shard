This copies a file and a directory into the running sandbox `web`, then lists the directory that holds them:

```sh
curl --unix-socket /var/lib/shard/shard.sock -T ./app.conf 'http://localhost/v0/sandboxes/web/files?path=/srv/app.conf&mode=600'
tar -cf - app | curl --unix-socket /var/lib/shard/shard.sock -T - 'http://localhost/v0/sandboxes/web/archive?path=/srv'
curl --unix-socket /var/lib/shard/shard.sock 'http://localhost/v0/sandboxes/web/ls?path=/srv'
```

To copy out, send a `GET` to the same route:

```sh
curl --unix-socket /var/lib/shard/shard.sock -o app.conf 'http://localhost/v0/sandboxes/web/files?path=/srv/app.conf'
curl --unix-socket /var/lib/shard/shard.sock 'http://localhost/v0/sandboxes/web/archive?path=/srv/app' | tar -xf -
```

Each route answers an error with the [Error](/docs/reference/api/#error) body, unless its responses say otherwise.

## Copy a file into a running sandbox

`PUT /v0/sandboxes/{id}/files` · scope `exec`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `path` | query | string | yes | The absolute path inside the sandbox. |
| `mode` | query | string | no | The permission bits in octal, at most 0777; absent is 0644. |
| `user` | query | string | no | The user who writes and owns the file; absent is the sandbox's user. |
| `parents` | query | boolean | no | Make the missing parent directories. |

**Request body**

binary as `application/octet-stream`, required.

**Responses**

| Status | Body | Description |
| --- | --- | --- |
| 204 | none | The file is written. The upload sets Content-Length to its number of bytes. |

## Copy a file out of a running sandbox

`GET /v0/sandboxes/{id}/files` · scope `exec`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `path` | query | string | yes | The absolute path inside the sandbox. |

**Responses**

| Status | Body | Description |
| --- | --- | --- |
| 200 | binary as `application/octet-stream` | The file's bytes, chunked to the end; a body cut short is a failed read. |

**Response headers**

| Header | Status | Type | Description |
| --- | --- | --- | --- |
| `X-Shard-Stat` | 200 | string | The stat of the path as JSON: type is file, dir, symlink or other; size is the logical size in bytes; mode is the permission bits as a number, at most 0o7777; then uid, gid and mtime. |
