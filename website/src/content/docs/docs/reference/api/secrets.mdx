This stores a secret named `API_KEY` for one destination, `api.example.com`:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X PUT -H 'Content-Type: application/json' -d '{"value":"<value>","destinations":["api.example.com"]}' http://localhost/v0/secrets/API_KEY
```

A create takes secrets by name, and so does the [grant](/docs/reference/api/sandboxes/#grant-a-secret-to-a-sandbox) to a stopped sandbox. No route returns a secret's value.

Each route answers an error with the [Error](/docs/reference/api/#error) body, unless its responses say otherwise.

## List secrets, never their values

`GET /v0/secrets` · scope `secret:*`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | integer (int64) | no | The most rows a page holds; none answers the whole list. At least 1. |
| `cursor` | query | string | no | The next of the page before; this page starts after it. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [SecretsResponse](#secretsresponse) as `application/json` |

## Create or rotate a secret

`PUT /v0/secrets/{name}` · scope `secret:*`

**Parameters**

| Name | In | Type | Required |
| --- | --- | --- | --- |
| `name` | path | string | yes |

**Request body**

[SecretRequest](#secretrequest) as `application/json`, required.

**Responses**

| Status | Body |
| --- | --- |
| 200 | [Secret](#secret) as `application/json` |

## Remove a secret

`DELETE /v0/secrets/{name}` · scope `secret:*`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | string | yes |  |
| `force` | query | boolean | no | Remove the secret even when a sandbox still has a grant on it. |

**Responses**

| Status | Body |
| --- | --- |
| 204 | none |
