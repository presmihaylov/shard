This links the sandbox `agent1` to the sandbox `web1`:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X PUT http://localhost/v0/sandboxes/agent1/links/web1
```

A link is one-way, and every sandbox that links `web1` sees it at the same address from `10.86.0.0/16`. A link stays through a stop and a start of either sandbox, a fork copies it, and the remove of `web1` drops every link to it. A create can carry links in its `links` field.

Each route answers an error with the [Error](/docs/reference/api/#error) body, unless its responses say otherwise.

## List the sandboxes a sandbox links

`GET /v0/sandboxes/{id}/links` · scope `sandbox:read`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [LinksResponse](#linksresponse) as `application/json` |

## Link a sandbox to another

`PUT /v0/sandboxes/{id}/links/{target}` · scope `ssh`

Every sandbox that links the target sees it at the same address, from 10.86.0.0/16, until no link names it. A PUT of a link the sandbox already holds changes nothing. The link outlives a stop of either sandbox, and goes when the target is removed. A target that does not exist, or the sandbox itself, answers 400 invalid\_request.

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `target` | path | string | yes | The id or name of the sandbox the link reaches. |

**Responses**

| Status | Body |
| --- | --- |
| 200 | [Link](/docs/reference/api/sandboxes/#link) as `application/json` |

## Remove the link to a sandbox

`DELETE /v0/sandboxes/{id}/links/{target}` · scope `sandbox:write`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `target` | path | string | yes | The id or name of the sandbox the link reaches. |

**Responses**

| Status | Body |
| --- | --- |
| 204 | none |
