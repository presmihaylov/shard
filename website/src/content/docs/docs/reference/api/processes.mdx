A process runs under shard-init in a running sandbox, by a name unique in that sandbox, and its restart policy says when it starts again. This runs a web server named `web` in the sandbox `site`:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X POST -H 'Content-Type: application/json' -d '{"name":"web","command":["python3","-m","http.server","8080"]}' http://localhost/v0/sandboxes/site/processes
```

This ends it, cancels its restarts and leaves the sandbox running:

```sh
curl --unix-socket /var/lib/shard/shard.sock -X POST -H 'Content-Type: application/json' -d '{"force":true}' http://localhost/v0/sandboxes/site/processes/web/kill
```

## Run a named process under supervision in a running sandbox

`POST /v0/sandboxes/{id}/processes` · scope `exec`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |

**Request body**

[RunRequest](#runrequest) as `application/json`, required.

**Responses**

| Status | Body |
| --- | --- |
| 201 | [Process](/docs/reference/api/sandboxes/#process) as `application/json` |

## Read or follow the output of a process

`GET /v0/sandboxes/{id}/processes/{name}/logs` · scope `sandbox:read`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `name` | path | string | yes | The process name. |
| `follow` | query | boolean | no | Keep the stream open until the process ends or the sandbox stops or is removed; a WebSocket upgrade requires follow=true. |

**Responses**

| Status | Body | Description |
| --- | --- | --- |
| 101 | WebSocket | A WebSocket follow with follow=true. Each binary message leads with its stream byte: 1 the output, 3 an EndMessage naming why the follow ended, 5 a FailureMessage. |
| 200 | string as `text/plain` | The process's output as it was written, every run the host keeps; with follow the body streams until the process ends or the sandbox stops or is removed. |

**WebSocket messages**

| Stream byte | Payload |
| --- | --- |
| 3 | [EndMessage](#endmessage) |
| 5 | [FailureMessage](/docs/reference/api/exec/#failuremessage) |

## Wait for or attach to a process until its restart policy ends it

`GET /v0/sandboxes/{id}/processes/{name}/attach` · scope `sandbox:read`

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string | yes | The sandbox id or name. |
| `name` | path | string | yes | The process name. |

**Responses**

| Status | Body | Description |
| --- | --- | --- |
| 101 | WebSocket | A WebSocket attach. Each binary message leads with its stream byte: 1 the output from the start of the current run, 3 the ended Process, 5 a FailureMessage. |
| 200 | [Process](/docs/reference/api/sandboxes/#process) as `application/json` | The process once its restart policy ended it. |

**WebSocket messages**

| Stream byte | Payload |
| --- | --- |
| 3 | [Process](/docs/reference/api/sandboxes/#process) |
| 5 | [FailureMessage](/docs/reference/api/exec/#failuremessage) |
