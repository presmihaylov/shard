[browser-use](https://github.com/browser-use/browser-use) drives a real Chromium. Here Claude Code is the agent: it calls browser-use as an MCP server, so there is no agent code to write. In a sandbox, the browser and the agent run away from your machine, and the host decides which sites they reach.

## Build the base once

Install browser-use, Chromium and Claude Code in a sandbox with no policy, then save its files as a snapshot:

```sh
shard create --name browser-base --memory 4GiB python:3.12
shard exec browser-base sh -c 'apt-get update && apt-get install -y libnss3-tools && useradd -m agent'
shard exec browser-base pip install "browser-use[cli]"
shard exec browser-base python -m playwright install-deps chromium
shard exec --user agent browser-base python -m playwright install chromium
shard exec --user agent browser-base sh -c 'curl -fsSL https://claude.ai/install.sh | bash'
shard exec --user agent browser-base /home/agent/.local/bin/claude mcp add -s user browser-use -- browser-use --mcp
shard stop browser-base
shard snapshot create --name browser-use browser-base
shard remove browser-base
```

A sandbox with no policy reaches the internet, so the installers can fetch from wherever they need. Every agent then starts from the snapshot and skips the install.

The agent runs as the `agent` user, because Claude Code refuses `--dangerously-skip-permissions` as root.

## Run an agent

Store your Anthropic key, allow Anthropic's API and Wikipedia with its images, and start an agent sandbox from the snapshot:

```sh
printf '%s' "$ANTHROPIC_API_KEY" | shard secret set --destination api.anthropic.com ANTHROPIC_API_KEY
shard policy create --allow api.anthropic.com --allow suffix:wikipedia.org --allow suffix:wikimedia.org --deny any browse
shard create --name browser-use-sbx --memory 4GiB --snapshot browser-use \
  --user agent --workdir /home/agent \
  --secret ANTHROPIC_API_KEY --policy browse \
  --env PATH=/home/agent/.local/bin:/usr/local/bin:/usr/bin:/bin \
  --env CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 --env DISABLE_AUTOUPDATER=1 \
  --env ANONYMIZED_TELEMETRY=false --env IN_DOCKER=true
```

The host reads HTTPS with its own certificate authority, and Chromium on Linux trusts only its own certificate store. Add the host's certificate to that store with a short script:

```sh title="trust-proxy.sh"
awk '/-BEGIN CERTIFICATE-/{c=""} {c=c $0 "\n"} END{printf "%s", c}' "$SSL_CERT_FILE" > /tmp/shard-proxy-ca.pem
mkdir -p ~/.pki/nssdb
certutil -d sql:$HOME/.pki/nssdb -N --empty-password
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n shard-proxy -i /tmp/shard-proxy-ca.pem
```

```sh
shard cp trust-proxy.sh browser-use-sbx:/home/agent/trust-proxy.sh
shard exec browser-use-sbx sh /home/agent/trust-proxy.sh
```

Give Claude Code a task:

```sh
shard exec browser-use-sbx claude -p --dangerously-skip-permissions \
  "Use the browser to open en.wikipedia.org and find the year the Eiffel Tower opened"
```

Claude Code opens Wikipedia through browser-use, finds the answer and prints it. To work with it interactively, run `claude` in `shard shell browser-use-sbx` instead.

## What the sandbox stops

- **The key stays on the host.** The agent holds `mock-ANTHROPIC_API_KEY`, and the host puts the real key into each request to `api.anthropic.com`. A page that tricks the agent into printing its environment gets only the placeholder. See [Give a sandbox an API key](/docs/guides/api-key/).
- **The browser reaches only the sites you allow.** A link to any other site fails to resolve. `shard policy logs browser-use-sbx` shows every page it tried, allowed or denied.
- **Your machine is out of reach.** The browser has no cookies, sessions or files of yours, and nothing private on your network.

`IN_DOCKER=true` makes browser-use start Chromium without its own sandbox. The shard sandbox is the boundary instead.

To let the agent browse more sites, add them to the policy. Run `shard policy create` again with the same name, and the running sandbox gets the new rules at once. `--allow any` opens the whole internet while the key stays on the host.

See [Run Claude Code in a sandbox](/docs/guides/claude-code/) for more on Claude Code itself.

## Clean up

```sh
shard remove --force browser-use-sbx
shard snapshot remove browser-use
```
